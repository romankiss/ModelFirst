# Tiny Light Explorer v0.15.2 · community baseline

Open **ModelCraft_TinyExplorer_v0.15.2.html**. The read-only community microLAR appears automatically; no installation, server or second ZIP selection is required.

## Your first route
Use **Skip to Yours Extension** on the introduction or standalone presentation for direct access to Examples → Package12 → Yours Extension. Remembered navigation and settings are browser-local where storage is available; export Package 0 to keep a portable copy of your task.

1. Architecture explains the approach. Examples offers Power ON, Pinging, ACK and Watchdog walkthroughs.
2. Choose Create package0, enter your human requirements, explicitly select a package12 foundation and optionally include a sequence diagram.
3. Give the ZIP to an AI assistant capable of ZIP IN/OUT. Review package1, then explicitly authorize Code-First. Download the UNVERIFIED package2 and handoff.
4. Open the result in Packages, inspect it, then use Placer and VS2022 to build, flash and test. Return evidence for scoped verification and a new pair.

**Package = State = Context.** A package carries its current contracts, implementation/provenance and evidence. It need not include the Explorer's entire development history. Root entry.json is the repository catalog; the exported task's entry.json is its pipeline workflow.

## HAL authoring preview
Examples → HAL adds scoped board-profile editing, Add row/Add board, plain-text Copy/Paste/Import/Export and persistent microLAR snapshots. Default comes from the declared pair DDR. Other repository artifacts remain read-only. Named or inline Integrate board tasks export a normalized hash-bound HAL artifact. See examples/HAL/README.md. New hardware acceptance is never inferred.

## Walking through packages
Workspace contains opened microLAR repositories and standalone packages. Navigate down through Packages; the breadcrumb preserves the path. HAL is a Tab immediately after Packages and is available only when the current package directly declares DDR HAL. It never searches nested pairs or other repositories. Back returns to the package; breadcrumb links return to ancestors. Active Micro LAR is the repository default; its actions are under the second-toolbar dots menu. Sources remain explicit in Examples package assembly.

## HAL board drafts and notes
Browser drafts restore the board, rows and current HAL view after reopening this Explorer in the same browser. Export text for portability. Board Notes are shared by PinMap and Resources, and travel with Human Request and text transfer. Omitted Notes leave the current value untouched on Paste; Notes: "" clears it. DELETE marks a target-board key for removal and is distinct from an empty cell, -1 and the draft-row ×.

Create package0 opens a docked editor. Navigate to HAL, copy Human Request (including Board Notes), then paste into the task. Collapse and Resume keep the draft in the current Explorer session. Browsing another package or switching the active repository does not change a chosen baseline or this draft’s repository inputs. Download the ZIP before leaving the session.

## Output naming and review corrections

New outputs use the Explorer-selected ModelCraft_ prefix; legacy CodeCraft_ inputs remain valid and immutable. Use the projection family, target version and output names from package0. Review corrections preserve the user-selected version and canonical filenames. A new target version requires a new user request. Record the prior and replacement SHA-256 and the correction reason. Retain the exact superseded archive at a content-addressed history path, preserving original review bytes; map the historical subject to its stored path. Bind the new OUT review to the replacement SHA-256. Only the candidate referenced by the active handoff may proceed.

## Module migration shortcuts

- `Integrate module: CAM -> MEDIA:EMPTY+CAM` — Move the existing source contract to the named destination resource; update affected composition, bindings, callers, subscriptions and tests. Remove the source from the new target composition; preserve the baseline.
- `Integrate module: CAM => MEDIA:EMPTY+CAM` — Copy the existing source contract to the named destination resource; retain the source in the target. Do not automatically activate a second instance of the same physical hardware.
