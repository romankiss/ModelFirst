MAX · Command options
CAM CAPTURE flags can be combined with |. A filename requires SD; the MAX default is last_capture.jpg.
AT+PUB=MEDIA,CAM,<ctx>,CAPTURE,LOG|SD,last_capture.jpg
SD paths are relative. READ defaults to metadata. DATA adds body, BASE64 sets its encoding, and LOG displays the content in AppLog.
AT+PUB=MEDIA,SD,<ctx>,READ,last_capture.jpg,DATA|BASE64
SD WRITE and APPEND default to UTF8 TEXT and accept explicit TEXT or BASE64. WRITE_LINE and APPEND_LINE add CRLF; empty text is allowed.
